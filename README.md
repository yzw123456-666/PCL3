# Plain Craft Launcher 3 (PCL3)

PCL3 是基于 [PCL2](https://github.com/Meloong-Git/PCL) 二次开发的 Minecraft Java 版启动器。在保留 PCL2 核心体验的基础上，移除了遥测与强制联网，并加入了内置防火墙与 AI 助手。

## 主要改动（相比原版 PCL2）

- **移除遥测**：删除全部匿名数据上报，启动器不再向任何服务器上传数据。
- **移除 MC 下载限制**：恢复被上游屏蔽的游戏客户端、Mod 与整合包下载。
- **移除强制联网**：移除配置更新、公告、土豆码等所有服务器连接，纯离线可用。
- **主题配色引擎**：修复开源版主题色相映射，完整支持 15 套主题与自定义 HSL。
- **内置防火墙**：
  - 启动前静态扫描 mods 文件夹，基于已知恶意家族特征与危险 API 启发式检测病毒 / 木马模组（如 fractureiser 家族）；
  - 启动门禁：发现威胁时提示或阻止启动，支持白名单；
  - 运行时监控：每 2 秒检查 Java 进程的可疑子进程（PowerShell / cmd / certutil 等），每 15 秒对比开机自启位置（注册表 Run 键、启动文件夹）检测持久化植入。
- **AI 助手**：配置 OpenAI 兼容接口（DeepSeek / Kimi / 智谱 GLM 等）后，可在报错时让 AI 分析原因与解决方案，或获取 Mod 推荐与新手教学。
- **哀悼日主题**：每年 10 月 20 日（PCL2 下架日）自动切换灰色调，可在 设置 → 彩蛋 中关闭。
- **彩蛋管理页**：直接体验滑稽彩 / 欧皇彩 / PLC 彩蛋等隐藏功能，并可调整滑稽彩轮换速度。

## 构建

### 依赖

- .NET Framework 4.8（运行时）
- .NET 9 SDK（编译 VB 代码需要 C# 13 编译器支持）
- Roslyn 4.8 编译器（已包含在 `工具/roslyn/` 中）

### 构建步骤

```powershell
# 1. 构建 C# 依赖库（首次）
dotnet build pcl3\PCLCS\PCLCS.csproj -c Release

# 2. 构建主程序（内测版）
powershell -ExecutionPolicy Bypass -File 构建.ps1

# 构建正式版
powershell -ExecutionPolicy Bypass -File 构建.ps1 正式版
```

构建产物输出到 `pcl3-成品\Plain Craft Launcher 3.<正式版>.<内测版>.exe`。

### 源码结构

| 路径 | 说明 |
|------|------|
| `pcl3/Plain Craft Launcher 2/` | VB.NET 主工程 |
| `pcl3/PCLCS/` | C# 辅助库（UI 控件等） |
| `pcl3/MeloongCore/` | C# 基础库（Shared / Wpf） |
| `pcl-2代码/` | PCL2 原版源码（只读参考，不参与构建） |

## 设置项说明

设置项均保存在本机注册表中，不上传。

| 设置页 | 主要功能 |
|--------|---------|
| 启动 | 版本隔离、窗口标题、内存分配、Java 选择等 |
| 联机 | EasyTier 局域网联机 |
| 个性化 | 主题、背景图、主页、音乐、动画速度 |
| 其他 | 下载设置、开发者模式、AI 助手、彩蛋 |
| 更衣室 | 3D 预览皮肤 / 披风，管理皮肤库 |
| 安全 | 防火墙总开关、模组扫描、运行时进程监控 |

## 安全说明

- **防火墙**：静态扫描为启发式检测，可能误报；所有阻断均提供「信任并继续」选项。白名单保存在本机注册表。
- **AI 助手**：API Key 加密保存在本机注册表；报错分析发送前会过滤访问令牌与 Windows 用户名，仅发送脱敏后的日志片段。
- **加密存储**：采用 Windows DPAPI（当前用户范围），密钥由操作系统保管；历史 DES 数据自动兼容读取。

## 隐私

PCL3 不向任何服务器上传数据，不收集遥测，不连接公告 / 配置更新服务器。唯一的外发网络请求来自：
- 你主动配置的 AI 接口（仅当你点击 AI 按钮时触发）
- Minecraft 游戏本体与 Mod 下载（直连 Mojang / CurseForge / Modrinth 官方源或镜像源）
